Target outcome

Four contracts drive everything.

These remain invariant across schema, API, UI, and analytics changes.

01

Three distinct tracks

DSA, LLD, and HLD retain independent goals, assignments, completion, and reporting.

02

Topic-aware assignment

Fresh, unsolved work gets randomized while protecting topic diversity and missed-item recovery.

03

Verified completion

System Design never accepts direct completion. Only a passed Optimus attempt writes solved state.

04

Safe code execution

LLD code runs outside Express with strict time, memory, output, and network controls.

API contract

Server owns every transition.

All mutating routes require authentication, validation, ownership checks, and idempotency.

GET/api/system-designList LLD or HLD items. Filter by topic, difficulty, and solved state.
PATCH/api/challenge/goalsValidate and persist DSA, LLD, and HLD targets for future days.
POST/api/assessmentsCreate or resume one active attempt for an owned problem.
GET/api/assessments/:attemptIdReturn safe question data. Never return rubrics or hidden tests.
PATCH/api/assessments/:attemptId/answers/:questionIdAutosave one answer using optimistic concurrency.
POST/api/assessments/:attemptId/code/runExecute visible tests through the isolated runner.
POST/api/assessments/:attemptId/submitLock answers, run hidden tests, grade rubrics, and finalize once.

Optimus state machine

Generate once. Grade once.

Retries create new attempts. Submitted question sets never mutate.

Passing rule: at least 8/10 overall, plus every required coding test. Objective answers and code grade deterministically. Free-text answers use a stored rubric.

Guardrails

Unsafe shortcuts stay forbidden.

Three boundaries need explicit enforcement and direct verification.

Arbitrary code

Never evaluate submissions inside Express. Disable outbound networking. Enforce CPU, memory, process, file, and output ceilings.

Critical

LLM trust

Validate every response. Keep rubrics server-only. Preflight code questions. Store exact prompts and outputs for grading disputes.

Critical

Source content

Import public catalog metadata only. Preserve attribution and original links. Do not mirror article bodies without permission.
